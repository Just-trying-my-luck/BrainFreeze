# Brain Freeze

A dedicated Raspberry Pi writing and project-reference system. 

## Project

Brain Freeze is a local writing-reference hub designed to organize:

- Characters
- Scenes
- Research
- Stage Business
- Voice Styles
- Miscellaneous Notes

## Hardware

- Raspberry Pi 5
- Display
- Physical Control Buttons
- Rotary Encoder
- 7-Segment timer display
- Status LEDs
- Freeze/safe-shutdown controls

## Software
Python 3
Raspberry Pi OS
Git
